# 조달온 — 공공조달관리사 학습 웹

공공조달관리사 필기 3과목을 공부한 뒤, 실기 공공조달 관리실무의 업무 절차와 사례 답안 작성을 이어서 연습하는 반응형 웹입니다.

접속 암호는 `jin`입니다. `node server.mjs`로 실행하면 서버가 암호를 확인한 뒤 8시간 유효한 HttpOnly 세션 쿠키를 발급합니다. 서버 재시작 시 다시 로그인해야 합니다. 기본 실행 암호는 `jin`으로 고정되어 환경변수 때문에 달라지지 않습니다. 암호 보호를 유지하려면 정적 파일만 배포하지 말고 이 Node 서버를 실행해야 합니다. 기본 서버는 로컬 주소에만 바인딩됩니다.

연습문제에서는 답안을 선택하지 않아도 **다음 문제**로 이동할 수 있습니다. 건너뛴 문제는 채점·오답 기록에 포함하지 않고, 결과에서 미완료로 표시합니다.

## 실행

Node.js 20.11 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
node server.mjs
```

브라우저에서 http://localhost:3000 을 엽니다. npm이 있다면 `npm run dev`도 사용할 수 있습니다. 포트는 `PORT` 환경변수로 변경할 수 있습니다.

- 이론·문제 북마크, 일일 활동 목표, 학습 진도, 연속 학습일

응시 중에는 질문·주어진 자료와 답안 입력만 표시합니다. 답안·문제 위치·시작시각·마감시각을 저장하여 새로고침·화면 이동 후 이어서 쓸 수 있습니다. 다른 화면에서도 제한시간은 계속되며 시간 종료 또는 만료 후 재접속 시 자동 제출합니다. 진행 중인 시험이 있으면 새 시험으로 덮어쓰지 않고 이어하기를 제공합니다.

제출 후 답안은 고정하고 모범답안·상세 풀이와 대조합니다. 체크 후 ‘이 문제 점검 완료’를 누르면 학습용 점수에 반영합니다. 각 문항을 동일 비중으로 두고 해당 문항의 점검 충족 비율을 적용하며 미응답은 0점입니다. 점검이 남아 있으면 잠정 점수로 표시하고, 체크 변경 시 해당 문항의 완료를 해제합니다. 서술 답안을 자동 정오 판정하거나 공식 합격 판정을 하지 않습니다.
