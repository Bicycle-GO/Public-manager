# 조달온 — 공공조달관리사 학습 웹

공공조달관리사 필기 3과목의 기본 개념을 공부하고 예상문제를 풀 수 있는 반응형 웹입니다.

## 실행

Node.js 20.11 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
node server.mjs
```

브라우저에서 http://localhost:3000 을 엽니다. npm이 있다면 `npm run dev`도 사용할 수 있습니다. 포트는 `PORT` 환경변수로 변경할 수 있습니다.

## 기능

- 제1편 공공조달관리사 필기: PART 01 6장 · PART 02 5장 · PART 03 7장, 총 18개 CHAPTER
- PART별 독립 목차 페이지, 해당 PART의 장별 탐색과 이전·다음 장, 핵심 요약과 학습 완료 표시
- 모든 단원에 학습 목표, 쉬운 용어 설명, 가상 업무 사례, 3단계 판단 과정, 비교표, 주의점, 펼쳐보는 자기점검 해설 제공
- 학습자료 모음: 과목별 학습 지도, 용어 검색, 기존 학습 진도와 연결한 14일 학습계획
- 18개 장의 핵심 심화 정리: 법령·전략조달·입찰·물품·용역·MAS·공사·하도급, 비교표와 풀이를 펼쳐보는 계산 예제 8개
- 학습문제 427개(PART별 176·135·116개, 객관식 407개·OX 20개): 이론과 분리된 문제 페이지, 즉시 채점, 해설, 관련 CHAPTER 연결
- CHAPTER별 예상문제 페이지와 단원별 핵심문제: 공공조달의 현대적 정의에 관한 사용자 제공 문항, 보기별 해설·가상 사례·공식 참고 자료
- 공유 대화 05~21번 핵심문제 17개: 단계별 풀이·보기별 해설·가상 공공기관 사례·암기 문장·문항 보정 사유. 공공조달 개요는 기존 2개와 합쳐 총 19문항이며 새 17문항만 따로 풀 수 있습니다.
- CHAPTER 02에 대화 22~25번 4문항 추가: 기존 4문항과 합쳐 8문항. 새 4문항 전용 풀이, 단계별 풀이·보기별 해설·가상 사례·암기 포인트 제공
- CHAPTER 02 첨부 예상문제 23개·OX 20개 추가: 기존 8개와 합쳐 51문항. 유형별 전용 풀이, 보기별 해설·암기 포인트, OX 채점·오답노트·북마크 지원

- 하루 5문제 무작위 학습
- 문제 풀이 상단의 목록 아이콘으로 해당 CHAPTER 예상문제 페이지 이동. 공유 문항도 풀이를 시작한 CHAPTER로 복귀하며 이미 채점한 기록 유지
- 60문항 연습형(과목별 20문항·90분, 기본값)과 80문항 실전형(30·20·30문항·120분): 중복 없는 객관식 무작위 출제, 과목 순서대로 풀이, 제출 후 채점, 시간 만료 시 자동 제출, 미응답 오답 처리

- 이론·문제 북마크, 일일 활동 목표, 학습 진도, 연속 학습일
- 브라우저 로컬 저장과 JSON 학습 기록 내보내기
- 모바일 화면 및 키보드 탐색 지원

## 콘텐츠 범위와 출처

입문용 자체 작성 이론과 연습문항입니다. 공식 기출이나 전체 시험범위를 대체하지 않습니다. 과목 구성과 안내는 국가기술자격법 시행규칙, 조달청, 정책브리핑을 참고했습니다. 앱의 시험 안내 화면과 각 단원에서 공식 출처로 이동할 수 있습니다. 상세 금액·기한·예외 요건은 현행 법령과 큐넷 출제기준을 확인하세요.

로그인·서버 데이터베이스는 사용하지 않습니다. 저장 기록은 같은 브라우저의 같은 출처에서만 유지됩니다. 로컬 기록을 삭제하면 복구되지 않으며, 내보낸 JSON은 보관용입니다. Google Fonts를 불러올 수 없으면 시스템 글꼴로 표시합니다.

2026. 9. 19. 자료는 연결된 ChatGPT 대화 「공공조달 필기과목 정리」의 목차·요약을 참고한 웹용 자체 작성 자료입니다. PDF·Word 원문 전재는 아닙니다. 2026. 9. 20. 사용자가 지정한 PART·CHAPTER 목차로 본문·사례·비교표·계산 예제와 14일 계획을 재구성했습니다. ‘총결 관리’는 문맥에 맞게 ‘종결 관리’로 정리했습니다.

기존 30문항의 ID·내용·정답·해설은 유지하고 관련 이론 연결만 변경했습니다. 이전 단원 주소는 관련 새 장으로 연결됩니다. 저장 기록은 `curriculumVersion: 2`로 한 번 변환하며, 북마크는 분리된 관련 장에 연결하고 기존 이론을 모두 읽은 경우에만 대응하는 장을 완료 처리합니다. 보강된 신규 장은 자동 완료하지 않습니다. 이전 단원 기록도 `previousCurriculum`에 보존합니다.

CHAPTER 02 기본이론에 공공조달 5대 기본원칙(투명성·VFM·경쟁성·차별금지 및 동등대우·책임성)을 보강했습니다. `basic-principles.js`는 원칙별 카드·가상 B군 드론촬영 사례·5년 비용 비교·원칙 비교표·8가지 분류 차이·자기점검 5개를 렌더링합니다. 이론 본문과 문제풀이의 관련 이론 창에서 함께 표시합니다. 조달청 2026년 표준교재 1권 69~71·122쪽과 연결된 대화 「공공조달 필기과목 정리」를 확인하여 작성했으며 교재 페이지나 첨부 이미지를 전재하지 않았습니다. 기존 예상문제 58개와 기록은 변경하지 않았습니다.

2026. 9. 24. 사용자가 제공한 5대 기본원칙 설명을 정리해 CHAPTER 02와 학습자료 검색에 반영했습니다. 핵심 의미·시험용 한마디 요약표, 8천만원·6천만원 서버 비교, 1억원 드론 용역 통합 사례, 투명성·동등대우·책임성 구별표, 경쟁성·VFM 비교와 ‘투·가·경·차·책’ 시험 포인트를 보강했습니다. 서버 사례는 같은 10년을 기준으로 추가 비용 정보가 필요함을 명시하고, 기존 5년 비용 계산은 펼쳐보는 예제로 제공합니다. 기존 참고자료 확인일과 이번 사용자 제공 내용의 업데이트일을 구분합니다.

같은 날 첨부된 예상문제·OX 풀이와 단원 핵심정리를 기본이론 및 문제은행에 반영했습니다. 객관식 전체 보기가 없는 자료이므로 제공된 정답 번호를 유지하고 선택지를 자체 재구성했음을 표시합니다. 객관식 01~23번은 ID 59~81, OX 01~20번은 ID 82~101을 사용하며 기존 ID 1~58은 유지합니다. 새 문항의 번호는 이전 대화 번호와 별도로 표시합니다. 각 문항에는 정답 근거·보기별 풀이·암기 포인트가 있으며, 수정한 문장은 보정 사유를 제공합니다.

기본이론은 5대 원칙에 이어 VFM·TCO, OECD 12원칙, 계약 참여범위·입찰 절차·낙찰자 결정의 구분, 수의계약·RFQ·분할계약, Sole/Single Source, ERA·정부구매카드, 이해충돌을 다룹니다. 법령 설명은 국가계약을 기준으로 합니다. 지명경쟁 인원과 예외, 긴급·특허 수의계약 요건, 공사 분할금지의 범위, 이해충돌 조치 예외, 견적절차와 기록 요건을 OECD·국가법령정보센터·법제처 자료와 대조해 보완했습니다. OX 16·20번은 자동 배제·고정 서류 의무로 단정하지 않도록 문장을 수정하고 O 정답 취지를 유지했습니다.

OX는 두 답안(O/X)을 실제 선택·채점하며 최근 답안·오답노트·북마크·일일학습에 반영됩니다. 모의고사는 기존 4지선다 형식을 유지하도록 객관식 문제은행에서 출제합니다(현재 407문항). `node --test tests/*.test.mjs`는 문항 ID·정답표·자료 출처 표시·해설·OX 복습·단원별 검색 및 기존 기록 호환을 검증합니다.

## CHAPTER 03 전자조달 제공자료 반영 (2026. 9. 24.)
